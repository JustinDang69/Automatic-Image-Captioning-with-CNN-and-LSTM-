# Colab notebook for PR #11: two decoding enhancements

Open [notebooks/06_colab_decoding_enhancements.ipynb](../notebooks/06_colab_decoding_enhancements.ipynb) on branch `feature/pr11-colab-decoding-source`. This file is part of [PR #12](https://github.com/JustinDang69/Automatic-Image-Captioning-with-CNN-and-LSTM-/pull/12), built on PR #11's decoding source.

The notebook includes an **exact, editable copy** of PR #11's `src/decoding_enhancements.py`. It runs **only** the following two strategies on the saved CNN–LSTM and VGG16 features:

- **Top-k sampling:** `top_k=3`, `RANDOM_SEED=42`
- **Length-normalised beam:** `beam_width=3`, `alpha=0.7`

The notebook does **not** produce separate greedy or unnormalised beam baselines. The original PR #11 greedy/beam functions remain the internal inference implementations.

## Google Colab steps

1. Open the notebook from this branch. Point `MODEL_DIR_OVERRIDE` (or `RUN_NAME`) at the folder containing `caption_model.keras` or `best_caption_model.keras`, `tokenizer.json`, `splits.json`, `metadata.json`.
2. If necessary, set `FEATURES_DIR_OVERRIDE` to the folder with `features.npy`, `image_ids.json`, `progress.npy`, and `metadata.json`. Provide Flickr8k through `DATA_DIR_OVERRIDE`, or let KaggleHub download it.
3. Execute cells in order. Source-code and binding cells use the notebook's copied PR #11 functions. Tests run before inference.
4. **Section 9** prints two actual model captions for each chosen image; **Section 10** displays images and all five reference captions. Example PNG/JSON are saved under the model run's `decoding_enhancements` folder.
5. **Section 12** automatically evaluates BLEU-1 to BLEU-4 on 20 validation images and shows a **two-row table**. Results are preliminary.
6. To report final corpus BLEU, set `RUN_FINAL_TEST_BLEU=True` in Section 1 and execute **Sections 13–14** on the full held-out test split. Results are saved as CSV/JSON and an updated plot. This may require substantial runtime.

The existing trained model is required; the repository does not contain model weights or feature arrays. No true captions or BLEU numbers have been generated by this GitHub change, and an end-to-end Colab run remains unverified.
